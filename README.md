# ApexSight

**ApexSight** is a native iOS client for [Frigate NVR](https://frigate.video) — your self-hosted AI security camera system, beautifully packaged for iPhone and iPad.

No cloud account. No subscription. Connects directly to your Frigate instance.

---

## Features

### Live Cameras
- **Sub-second WebRTC live** via go2rtc — native decode, no WebView. Frigate **0.18 removed the
  nginx HLS proxy route**, so live is WebRTC-primary with an automatic MJPEG fallback; on 0.17 the
  app probes and still prefers HLS.
- **Dual-URL auto-switch** — a separate local URL is used automatically when you're on your home
  Wi-Fi and the remote one when you're away, verified by a reachability probe (same JWT for both)
- **Host-only ICE on the LAN** — skips the STUN/TURN round trip at home, so cameras open in ms
- **Pinch-to-zoom** on live video, recorded clips, and snapshots (up to 6×)
- **Multi-camera wall** — 1, 2, 3, or 4-up live grid with saved layouts; the wall plays the lighter
  `_sub` streams while the full-screen viewer plays full-res `main`
- **Instant snapshot placeholder** — camera image shown immediately while the stream connects
- **Picture-in-Picture** — keep watching while using other apps (stops if the biometric lock engages)

### Doorbell
- **CallKit calls** — a doorbell press rings both phones like a real call, via a VoIP push
- **Live two-way talk** — hold to talk; your mic is published over WebRTC and piped to the
  doorbell's speaker natively over the LAN (no cloud, no vendor app)
- **Soundboard** — saved clips and text-to-speech replies playable at the door
- **Ring debounce** — a visitor mashing the button rings once, not repeatedly

### Alerts & Review
- **Real-time alerts** via Frigate's stock WebSocket — new reviews appear in under a second
- **In-app banner** for new alert-severity events while the app is open
- **Review tab** — full history with severity filter, detection chips, date/time stamps
- **Activity tab** — event list filtered by camera and object label
- **Event detail** — auto-playing clip, snapshot, zones, confidence, face/plate recognition

### Rich Notifications
- **Background alerts** via iOS Background App Refresh (no setup required)
- **Instant push** — optional companion service for alerts when the app is closed
- **Rich attachments** — GIF preview or snapshot thumbnail downloaded by the notification extension
- **Action buttons** — Open, Reviewed, Snooze directly from the lock screen
- **Deep links** — tap a notification to jump straight to the review or camera

### Timeline & Search
- **Recording browser** — day picker, hour-by-hour heat map, direct MP4 clip playback
- **Semantic search** — describe what you saw; also filter by camera, label, zone, date, license plate
- **Face & license plate recognition** — surfaced in event rows, detail views, and search (Frigate 0.15+)

### House Modes
- **Home / Away / Night**, synced with Home Assistant's Alarmo — arming from any phone, a widget,
  Siri or the watch reflects everywhere within one poll
- **Per-mode camera matrix** — choose which cameras alert in each mode; the setting is
  household-wide and mirrors into Frigate's own per-camera alert switches
- **Visible household gate** — an active snooze or disarm shows a banner naming **who** set it and
  **when**, so "why am I not getting notifications?" answers itself

### Settings & Management
- **Multiple Frigate servers** — add, switch, and remove servers from Settings
- **Notification preferences** — per-camera, per-object, per-zone toggles; quiet hours; snooze;
  custom triggers. Household-wide snoozes are distinguished from a **per-device iOS Focus mute**,
  so one person's Do Not Disturb never silences everyone else's cameras.
- **PTZ controls** — on-screen directional pad for supported cameras
- **System health** — detector stats, storage, camera capabilities
- **Lock Screen & Home Screen widgets** — latest camera snapshot with freshness indicator
- **Live Activities** — active alert on Lock Screen and Dynamic Island
- **Apple Watch, CarPlay, and Apple TV** companions
- **Siri & Shortcuts** — "latest alert", "recent activity", arm/disarm, open a camera, snooze
- **Biometric app lock** — optional Face ID gate, which also stops an active PiP window
- **Daily recap** — an end-of-day summary push, scheduled on the relay so it fires app-closed

## Requirements

- iPhone or iPad running **iOS 17+**
- Self-hosted [Frigate NVR](https://frigate.video) instance (local or accessible remotely)
- Frigate authentication enabled
- go2rtc configured (included with Frigate by default) — WebRTC for live view
- Optional: the **ApexSight Push** Home Assistant add-on for instant app-closed alerts,
  doorbell CallKit calls and two-way talk (separate repo, see below)

## Building

The app is a native SwiftUI project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen).
A Mac with **Xcode 26.5** (the released SDK) is required.

> **Ship with the released SDK.** App Store Connect rejects uploads built against a **beta** iOS SDK
> (`ITMS-90534`), so archive with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`, not an
> `Xcode-beta.app`. One iOS 27-only symbol (`toolbarMinimizeBehavior`) is guarded behind
> `#if compiler(>=6.4)` and returns automatically when built against an iOS 27 RC.

```bash
# Install XcodeGen (one-time)
brew install xcodegen

# Clone and generate the Xcode project
git clone https://github.com/btoth525/ApexSight.git
cd ApexSight/native-ios
xcodegen generate
open ApexSightNative.xcodeproj
```

In Xcode: select your device → **⌘R** to build and run.

**Signing:** Open project settings → Signing & Capabilities → select your Apple Developer team. Update the bundle ID prefix in `project.yml` to match your own identifier before building.

## Optional: Instant Push Companion

For alerts when the app is fully closed — plus doorbell CallKit calls and live two-way talk — run
the **ApexSight Push** Home Assistant add-on:
[`btoth525/apexsight-ha-addon`](https://github.com/btoth525/apexsight-ha-addon). It bundles the APNs
relay (with a web GUI for your Apple `.p8`) and the Frigate MQTT bridge in one container. No Frigate
modifications required.

The older standalone `frigate-integration/apns_notifier.py` predates it and is kept for reference.

## Privacy

- All data stays on your network. Nothing is sent to third-party servers.
- Frigate credentials, the household pairing code and the disarm code live only in the iOS
  Keychain, in the app's own private access group — not in app-group preferences. The alarm code
  is held at a stricter accessibility class than the session token.
- No analytics, no telemetry, no accounts.
